# Elevate Labs AI/ML Internship

This repository contains the Artificial Intelligence and Machine Learning projects completed during my **Elevate Labs AI/ML Internship**.

The projects demonstrate practical implementation of Machine Learning, Natural Language Processing, model evaluation, data preprocessing, and deployment using Python and related tools.

---

## 📌 Projects

### 1. Fraud Detection in Credit Card Transactions

An end-to-end Machine Learning project for identifying potentially fraudulent credit card transactions.

**Key techniques used:**
- Data preprocessing and cleaning
- Exploratory Data Analysis (EDA)
- Handling highly imbalanced data
- Logistic Regression
- Random Forest
- XGBoost
- Isolation Forest
- Threshold tuning
- Model evaluation
- Feature importance analysis
- Batch prediction
- Streamlit web application

**Main technologies:**
`Python` `Pandas` `NumPy` `Scikit-learn` `XGBoost` `Streamlit` `Joblib`

**Project folder:**  
`Fraud-Detection-in-Credit-Card-Transactions/`

The project includes the trained model, Jupyter Notebook, prediction module, Streamlit application, requirements file, and project documentation.

---

### 2. News Article Classification

An NLP-based Machine Learning project for classifying news articles as **Fake** or **Real**.

**Key techniques used:**
- Text preprocessing
- Tokenization
- Stopword removal
- Text cleaning
- TF-IDF Vectorization
- Logistic Regression
- Multinomial Naive Bayes
- Accuracy, Precision, Recall and F1-score evaluation
- Confusion Matrix
- Streamlit web application

**Main technologies:**
`Python` `Pandas` `NLTK` `Scikit-learn` `TF-IDF` `Joblib` `Streamlit`

**Project folder:**  
`News-Article-Classification/`

The project includes the Jupyter Notebook, trained models, TF-IDF vectorizer, Streamlit application, requirements file, and documentation.

> **Note:** The News Article Classification project is a text-classification demonstration. A model prediction does not establish whether a news article is factually true or false.
